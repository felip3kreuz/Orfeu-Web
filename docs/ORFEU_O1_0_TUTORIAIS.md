# Tutoriais do Orfeu Web O1.0

Os três tutoriais estão disponíveis no botão **TUTORIAL** na barra lateral do painel autenticado.

## Aluno

1. Espaço do aluno e menu de navegação.
2. Criação/seleção do empreendimento.
3. Persona.
4. Lean Canvas.
5. Canais e ferramentas digitais.
6. Decisões semanais (turnos simulados, não semanas reais).
7. Finanças.
8. Indicadores.
9. Parecer do Mentor em MINHA EMPRESA.

## Mentor

1. Espaço do Mentor.
2. Visão geral.
3. Cenários pedagógicos.
4. Turmas atribuídas.
5. Alunos matriculados.
6. Resultados sincronizados.
7. Aprovação/Reprovação e parecer pedagógico.

## Administrador

1. Espaço do Administrador.
2. Visão geral.
3. Comandos de cadastro, turma e importação.
4. Gestão de turmas/matrículas.
5. Contas e vínculos.
6. Importação CSV.
7. Segurança, primeiro acesso e correio eletrônico.

Os exemplos são fictícios e **nenhuma etapa executa ações administrativas, pedagógicas ou financeiras de verdade**.

## Persistência e comportamento

- O sistema oferece o tutorial no primeiro acesso daquele navegador para cada usuário/perfil.
- O usuário pode escolher **INICIAR TUTORIAL** ou **AGORA NÃO**.
- Durante o roteiro, **ANTERIOR**, **PRÓXIMO**, **CONCLUIR**, **REINICIAR** e **SAIR** organizam a navegação.
- A opção **TUTORIAL** pode ser acionada novamente a qualquer momento; se o roteiro foi concluído, recomeça na primeira etapa.
- Um roteiro interrompido é retomado pelo último passo salvo naquele navegador; o estado não é sincronizado entre aparelhos.
- Esc fecha o roteiro e as setas esquerda/direita navegam entre os passos.
- O tutorial nunca acessa diretamente APIs que alteram dados, nem cria registros.
- Os elementos destacados são da interface real; se não estiverem disponíveis (por exemplo, empresa ainda não criada), o tutorial aponta a área do módulo correspondente.
