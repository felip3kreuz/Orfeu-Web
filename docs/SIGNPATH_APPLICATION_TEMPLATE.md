## Project description

JED Simulador is an open-source educational entrepreneurship simulator designed to support learning activities related to the Jovens Empreendedores Digitais (JED) program.

Students can create simulated businesses, work with Persona and Lean Canvas, choose digital channels and tools, make weekly business decisions and analyze operational, commercial and financial indicators.

Tutors can organize classes, configure pedagogical scenarios and review synchronized student results when the optional online mode is used.
