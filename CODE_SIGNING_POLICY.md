`https://github.com/SEU_USUARIO_GITHUB/JED-Simulador`

Substitua `SEU_USUARIO_GITHUB` pelo usuário ou organização real antes de solicitar a aprovação da SignPath Foundation.

## Funções da equipe

### Authors / Committers

- `SEU_USUARIO_GITHUB` — mantenedor responsável pelo desenvolvimento e manutenção do código.

### Reviewers

- `SEU_USUARIO_GITHUB` — responsável por revisar contribuições externas antes do merge.

### Approvers

- `SEU_USUARIO_GITHUB` — responsável por aprovar cada solicitação de assinatura de release.

Se outras pessoas passarem a integrar formalmente a manutenção do projeto, esta seção deve ser atualizada.

## Política de privacidade

Consulte [PRIVACY.md](PRIVACY.md).

Em particular:

> This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

## Processo de assinatura

1. O código da release deve estar versionado neste repositório.
2. O build deve ser executado por GitHub Actions em runner hospedado pelo GitHub.
3. Os artefatos devem ser produzidos a partir do commit/tag correspondente à release.
4. A solicitação de assinatura deve utilizar a integração oficial do SignPath com GitHub.
5. Cada release assinada deve receber a aprovação manual exigida pela SignPath Foundation.
6. O projeto não utilizará a assinatura da SignPath Foundation para binários de terceiros.
