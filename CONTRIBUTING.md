# Contribuindo

Contribuições por issue ou pull request são bem-vindas.

## Antes de enviar código

1. Execute `go test ./...`.
2. Execute `go run . --self-test`.
3. Não inclua senhas, tokens, dados pessoais de alunos ou arquivos gerados localmente.
4. Explique claramente a alteração proposta.
5. Mudanças nos workflows de build ou assinatura devem ser revisadas com atenção especial.

## Revisão

Pull requests de pessoas sem permissão de commit devem ser revisados por um mantenedor do projeto antes do merge.
